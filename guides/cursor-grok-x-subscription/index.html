Cursor、Grok 与 X 新订阅，到底怎么选？

看到新旧套餐、共享额度和迁移选项头都大了？先别急着付款。我按七种使用场景，整理了一个尽量简单的选择思路。

到底怎么选？

最近 Cursor、Grok 和 X 的订阅整合成了 The X Subscription。乍一看，统一付费似乎更方便，但实际选择时有三个容易被忽略的细节：共享用量池、第三方模型额外计费，以及切换旧订阅后无法撤销合并。

本文依据 2026 年 10 月 17 日可查的官方说明整理。价格和权益变化很快，实际下单以结账页面为准。本文为独立使用指南，不是官方销售建议。

先看新方案价格

方案月付年付适合谁
Free$0$0先尝试的人
Plus$8$80轻量使用者
Premium$30$300日常 AI / Bot 用户
Super$100$1,000高频使用者
Ultra$200$2,000非常重度使用者

这里是官方美元标价，不是某个地区的最终税后价格。年付显示的是全年一次付款金额，不等同于按月随时取消。Grok Bot 从 Premium 档开始包含；新方案的 Grok 与 Cursor 有一份共享的每周用量。

按这 7 种情况选

  1. 只是想了解新功能，还不确定用不用得上先试 Free。与其为了“套餐看着很值”立刻付钱，不如先明确你实际会使用哪种工具。
  2. 偶尔使用 AI，预算比较敏感可以看 Plus（$8/月），但要接受它不含 Grok Bot。轻度体验和自动化 Agent 是两种不同需求。
  3. 你希望日常使用 Grok，还想用 Grok Bot从 Premium（$30/月）开始比较，因为 Plus 并不包含 Grok Bot。这个档位也是多数中等使用者可以先研究的起点。
  4. 你经常用 Cursor 写代码，但主要调用 Claude 或 GPT别只比较订阅价格。新套餐中，Cursor 的第三方模型使用按额外费用计算，可能让原本看似便宜的方案变贵。
  5. 你大量使用 Grok 和 Cursor 的自家模型再比较 Super（$100/月）及其用量池大小。只有确认 Premium 的额度确实不够，升级才有意义。
  6. 你是每天高强度工作、持续消耗大量额度的用户才需要认真评估 Ultra（$200/月）。它不是“越贵越好”，而是给明确知道自己需要大用量的人准备的。
  7. 你已经持有旧版 Cursor、SuperGrok 或 X 会员先别急着合并。官方允许符合条件的旧订阅继续使用；切换会取消所选旧方案，合并不可逆。尤其是有优惠价、旧权益或 App Store 账单时，先算清楚。

有三个坑，付款前一定要看

01 · 共享用量 ≠ 每个产品各领一份

新套餐的符合条件的 Grok 和 Cursor 使用，共享按周刷新的用量池。Grok Bot 也从同一池子扣除。不能简单把各产品显示的额度直接相加。

02 · Cursor 里的第三方模型不是免费附赠

在新套餐里，Cursor 内的 Claude、GPT 等第三方模型不计入套餐自带的用量，从首次使用起就可能按 API 价格通过预付额度计费。如果你主要依赖这些模型，这是购买前最该核实的项目。

03 · 老用户切换前要核对账单

符合条件的旧订阅可以保留，不是必须统一。切换时选定的旧订阅会取消，未用完部分通常按比例退款；但通过 Apple App Store 支付的 Cursor 订阅不会被自动取消，需要自己在 Apple 订阅里处理。合并不可逆，所以旧优惠权益最好先确认。

我的简短建议

如果你只是好奇，就先试用；如果真正需要 Grok Bot，可以从 Premium 开始评估；如果主要是 Cursor + Claude/GPT，重点算额外模型费用；如果手里已有划算的旧套餐，先不要冲动迁移。

订阅不是越统一越划算。先看自己真正常用什么，再看一个月愿意花多少钱。
